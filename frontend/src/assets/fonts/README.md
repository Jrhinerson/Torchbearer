# Inter Variable

Unmodified Latin and Latin Extended variable WOFF2 files from
[`@fontsource-variable/inter` version 5.3.0](https://github.com/fontsource/font-files/tree/main/fonts/variable/inter).
Both normal and italic faces support weights 100 through 900. Other scripts use the UI's system fallback fonts.

The npm package's SHA-512 integrity was checked before copying these assets:

```text
sha512-OupL48va4JNofb97w6NYeF9S7W/kHNKM0Er8Dem5nqi4jeOLrVJDoE8tZEpnMJmtkvNbB1EIPPwHcdkF6b1oUA==
```

in `../../app/styles/fonts.css` keep extended and italic assets demand-loaded.
